# Проект "Интернет-магазин"

## Описание

В проекте реализовано ядро для интернет-магазина без интерфейса.

### Описание модулей

В пакете **src** находятся модули с основным функциональным кодом:

В модуле **product** находится класс __Product__ для представления товаров.

В модуле **category** находится класс __Category__ для представления категорий и их подсчета, а также подсчета кол-ва
товаров в категории.

В модуле **utils** находятся вспомогательные функции:

- __read_json__ для чтения json-файлов
- __create_objects_from_json__ для создания объектов класса.

В модуле **settings** находятся пути к корневой директории проекта и к необходимым файлам.

В модуле __product_iterator__ реализован итератор, который перебирает все товары категории. Возвращает их по одному.

В модуле **smartphone_category** описан класс Smartphone, наследник класса Product. Описывает категорию товаров Смартфоны. Дополнен указанием модели, памяти и цвета.
 
В модуле **lawngrass_category** описан класс Lawngrass, наследник класса Product. Описывает категорию товаров Трава газонная. Дополнен указанием страны-производителя, срока прорастания и цвета.
 
 
### Установка

1. Клонируйте репозиторий

```commandline
git clone git@github.com:LifanovaTatiana/prj3_OOP.git

```

2. Установите зависимости

```commandline
poetry install
```

### Тестирование

Проект покрыт юнит-тестами Pytest. Они располагаются в пакете **tests**

Чтобы запустить тесты с оценкой покрытия выполните команду:

```commandline
poetry run pytest --cov
```
